# Zico, o Samurai de Quintino

Site oficial do documentário "Zico, o Samurai de Quintino", dirigido por João Wainer. O projeto apresenta a história do lendário jogador de futebol Arthur Antunes Coimbra, o Zico, desde suas origens no bairro de Quintino, no Rio de Janeiro, até se tornar um ícone mundial do esporte.

## 📂 Estrutura do Projeto

```
zico-o-samurai-de-quintino/
├── assets/
│   ├── css/
│   │   └── style.css         # Estilos globais
│   ├── fonts/                # Fontes do projeto
│   ├── img/                  # Imagens e assets visuais
│   └── js/
│       └── main.js           # Lógica principal e interatividade
├── index.html                # Página principal
└── README.md                 # Documentação do projeto
```

## 🎨 Design Tokens

O projeto utiliza variáveis CSS para consistência visual:

- **Cores**: `--color-red`, `--color-white`, `--color-black`, `--color-dark`, `--color-text-muted`, `--color-overlay-bg`
- **Fontes**: `Hanken Grotesk` (Regular e Bold)
- **Transições**: `var(--transition-fast)`, `var(--transition-menu)`

## 📱 Responsividade

O site é totalmente responsivo e otimizado para diferentes dispositivos:

- **Mobile**: Design vertical com menu hamburger e navegação sobreposta.
- **Desktop**: Layout horizontal com lista de patrocinadores no header.

## 🔍 SEO

O projeto inclui:

- **JSON-LD**: Dados estruturados para schema.org/Movie.
- **Meta Tags**: Open Graph e Twitter Cards para compartilhamento em redes sociais.
- **Acessibilidade**: Atributos ARIA, navegação por teclado e foco visual.
